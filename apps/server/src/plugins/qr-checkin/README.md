# QR code check-in plug-in (FR 3.16, P3)

Not implemented yet — scheduled for **phase 4**.

A QR code is mailed with the registration confirmation and scanned on site
(UC 16). Lowest rated event-management function in the survey (2.74), hence P3
and last in the phase 4 order. Needs camera access in the participant client,
which is one reason the participant client ships as an installable PWA.

Follows the structure of `../room-planning`, the reference implementation of the
plug-in contract.
