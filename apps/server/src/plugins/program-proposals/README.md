# Programme proposals plug-in (FR 3.13, FR 3.14, P2)

Not implemented yet — scheduled for **phase 4**, and first in that phase's
priority order.

Participants suggest programme items (UC 13); the organizer moderates and
approves them, and the proposal's status stays visible to the person who
submitted it.

Follows the structure of `../room-planning`, the reference implementation of the
plug-in contract.
